# 歴代天皇126

神武天皇から第126代まで、一代ずつ順番に表示するスマートフォン向けPWAです。

## GitHub Pagesで公開する方法

1. このフォルダ内のファイルをGitHubリポジトリのルートへアップロードします。
2. GitHubのリポジトリで `Settings` → `Pages` を開きます。
3. `Build and deployment` の Source を `Deploy from a branch` にします。
4. Branchを `main`、フォルダを `/ (root)` にして保存します。
5. 表示されたURLをスマートフォンで開きます。

## 主な仕様

- 神武天皇から第126代まで順番に表示
- 左側「次へ」70%、右側「前へ」30%
- 矢印表示なし
- 最後に見た天皇を端末内に保存
- オフライン表示対応
- iPhoneの「ホーム画面に追加」に対応

## データについて

第126代が現在の天皇であることは、宮内庁の案内に基づいています。
歴代天皇名・読みは、公開前に用途に合わせて最終確認してください。
